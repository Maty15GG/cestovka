# Cesty s příběhem – ukázkový web cestovní kanceláře

Moderní responzivní prezentační web pouze v HTML a CSS. Určený jako designová ukázka / portfolio projekt.

## Otevření v editoru
1. Otevři složku `cesty-s-pribehem` ve Visual Studio Code.
2. Otevři `index.html` přes prohlížeč nebo rozšíření Live Server.
3. Na GitHub nahraj `index.html` a `style.css` do stejného repozitáře.
4. V GitHub Settings → Pages vyber Deploy from a branch → main / root.

## Co je hotové
- Responzivní design, sekce zájezdů, informace o cestovní kanceláři, náhled klientské zóny
- SEO title, description, sémantická struktura HTML
- Připravený vizuální rezervační formulář (bez odesílání)

## Co NENÍ součástí
- Skutečný redakční systém (CMS) a administrace zájezdů
- Registrace, přihlášení a zákaznický portál
- Online rezervace, platby, generování zpráv a bezpečné ukládání dat
- Funkční kontaktní formulář

Pro takové funkce je potřeba backend, databáze, zabezpečení, případně platební brána. GitHub Pages podporuje statické weby, nikoli vlastní serverovou aplikaci.

## Před předáním klientovi
- Nahradit fiktivní značku, ukázkové zájezdy, ceny, kontakty a fotografie schválenými podklady.
- Doložit oprávnění k obrázkům a textům; externí fotografie jsou z Unsplash a jejich dostupnost/užití je nutné ověřit.
- Otestovat mobil, přístupnost, odkazy a SEO. Dodat potřebné právní informace.
